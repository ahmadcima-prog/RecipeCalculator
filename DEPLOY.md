# Recipe Phone App — Deploy to GitHub Pages (Android install)

This folder is a ready-to-publish **PWA** (Progressive Web App).
Once hosted on GitHub Pages, you can install it on Android like a real app:
an icon on the home screen, fullscreen, works offline.

> Files here are regenerated by `UpdateCalculator.bat` (or
> `python backend\build_calculator.py`) after every recipe change.

---

## ONE-TIME SETUP (~5 minutes)

### Step 1 — Create the GitHub repository
1. Go to <https://github.com> and sign in (create a free account if needed).
2. Click **+** (top-right) → **New repository**.
3. Name it, e.g. `recipe-phone-app` — visibility: **Public** (required for
   free GitHub Pages) → click **Create repository**.
4. **Do NOT** add a README / .gitignore / license on that page (keep empty).

### Step 2 — Put these 5 files into the repo
Choose ONE of the two ways:

**Way A — Upload in the browser (easiest, no git needed)**
1. Open your new repo page → click **uploading an existing file** link.
2. Drag ALL 5 files from this folder into the browser
   (`index.html`, `manifest.webmanifest`, `sw.js`, `icon-192.png`, `icon-512.png`).
3. Click **Commit changes**.

**Way B — With git (double-click `publish_phone_app.bat` in the project
root after connecting the remote once):**
```bat
cd phone-app
git init
git add -A
git commit -m "Recipe phone app"
git remote add origin https://github.com/YOURUSERNAME/recipe-phone-app.git
git branch -M main
git push -u origin main
```

### Step 3 — Turn on GitHub Pages
1. In your repo: **Settings** → **Pages** (left menu).
2. **Source:** `Deploy from a branch` · **Branch:** `main` · folder: `/ (root)`
3. Click **Save** and wait 1–2 minutes.
4. Your app URL appears, like:
   `https://YOURUSERNAME.github.io/recipe-phone-app/`

### Step 4 — Install on your Android phone
1. Open **Chrome** on the phone and go to that URL.
2. Log in (same usernames/passwords as the PC app).
3. Tap the **⋮** menu → **Add to Home screen** → **Install**.
4. A **"Recipes" icon** appears on the home screen — it opens fullscreen
   and works **offline** after the first load.

---

## AFTER EVERY RECIPE CHANGE

1. On the PC: double-click **`UpdateCalculator.bat`** — it rebuilds this
   folder with the new data (the service-worker cache version is bumped
   automatically, so phones pick up the update).
2. Push the update: double-click **`publish_phone_app.bat`** (or upload the
   new `index.html` + `sw.js` in the browser as in Step 2).
3. On the phone: just open the app once — it updates itself in the
   background, no reinstall needed.

---

## ⚠️ Privacy note

`index.html` embeds your recipes **and the user list with passwords** (needed
for offline login). A **public** GitHub Pages URL means anyone with the link
can read that data. Keep the link private, use an unguessable repo name, or
use a private repo with GitHub Pro. Ask for help if you want the password
check removed from the phone version instead.
